# Pico v1 产品需求文档

## 定位

Pico 是一款暗黑、冰蓝、键盘优先的 macOS 本地剪贴板工具。它帮助用户在不同应用之间快速找回、整理和再次粘贴复制过的内容，同时保留明确的隐私边界。

## v1 用户价值

- 用 `⌘ ⇧ V` 立即打开历史，不离开当前工作流。
- 用左右键和 Return 完成选择与粘贴。
- 用手动分组建立项目、常用回复和开发资料等上下文。
- 用本地 OCR 搜索图片中的文字。
- 主动调用用户配置的 OpenAI-compatible 模型，把中文翻成英文或其他语言翻成简体中文。
- 通过签名公证 DMG、Sparkle 和 Homebrew 安全安装更新。

## 不在范围内

iOS、CloudKit、多设备同步、AI 对话、自动翻译、自动总结、智能分组、图片钉屏和 App Store 构建。

## 验收标准

- macOS 14+ 上可构建并启动菜单栏应用。
- 剪贴板复制后不弹窗；历史面板只由快捷键或菜单主动唤起。
- 文本、富文本、图片、文件、链接和代码可被记录、搜索和粘贴。
- 收藏项不会被保留策略删除；重复内容不会产生重复记录。
- 分组支持多重成员关系及批量操作。
- OCR 在后台执行且失败不阻塞图片入库。
- AI 翻译请求仅在用户触发后发出；结果通过灵动岛展示，复制由用户点击完成。
- 无 Developer ID 凭据时仍可完成本地 Debug/Release 构建；发布流水线在凭据补齐后可运行。
