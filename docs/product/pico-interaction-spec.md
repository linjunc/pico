# Pico v1 交互规格

## 1. 产品体验原则

Pico 是一款仅面向 macOS 的本地剪贴板工具。视觉以暗黑和冰蓝为主，交互强调快速、克制和键盘优先。

- 默认使用 `⌘ ⇧ V` 显示或隐藏剪贴板面板。
- 面板默认采用横向布局，保留 Paste 用户熟悉的操作节奏。
- 不因复制动作自动弹窗，不抢占当前工作流。
- 涉及网络的翻译必须由用户主动触发。
- 历史数据默认只保存在本机；模型 API Key 存入 macOS Keychain。

## 2. 剪贴板面板

### 2.1 显示与关闭

1. 用户按 `⌘ ⇧ V`。
2. Pico 记录当前前台应用并显示面板。
3. 用户按 `Esc`、再次按 `⌘ ⇧ V`、完成粘贴或点击面板外部时关闭面板。
4. 关闭后把焦点归还给原应用。

### 2.2 导航与操作

| 输入 | 行为 |
| --- | --- |
| `←` / `→` | 循环选择上一条或下一条内容 |
| `Return` | 保留格式粘贴当前条目 |
| `Shift + Return` | 以纯文本粘贴当前条目 |
| `T` | 翻译当前选中的文本条目 |
| `⌘ 1…9` | 快速粘贴当前结果中的第 1～9 条 |
| `Esc` | 关闭面板并返回原应用 |

鼠标用户可以单击选中条目，通过右键菜单执行粘贴、纯文本粘贴、翻译、收藏、添加到分组、预览和删除。

## 3. AI 模型配置

### 3.1 模型实体

每个模型实体包含：

- 显示名称：用户用于识别配置的本地名称。
- Base URL：OpenAI-compatible API 根地址，例如 `https://api.openai.com/v1`。
- API Key：写入 Keychain，设置界面只显示掩码。
- 模型 ID：直接写入 Chat 请求的 `model` 字段。

首版只实现 OpenAI-compatible Chat 接口，不适配厂商私有协议。用户可以配置云端服务、代理服务、Ollama 或 LM Studio 等兼容端点。

### 3.2 模型列表

- `GET /models` 仅作为可选的输入辅助，不是保存模型的前置条件。
- 获取成功时，用户可以从返回结果选择模型 ID。
- 获取失败、未实现或无权限时，保留手动输入的模型 ID，并显示非阻断提示。
- 不因为模型列表失败而把模型实体标记为不可用。

### 3.3 连接测试

- “测试 Chat”向 Chat 接口发送最小请求，验证 Base URL、Key、模型 ID 和响应解析。
- 测试成功后显示“Chat 接口连接成功”。
- 测试失败时展示服务返回的可理解错误，但不得显示完整 API Key。
- 允许用户不测试直接保存；首次实际翻译失败时再通过灵动岛反馈。

## 4. 主动翻译

### 4.1 入口

翻译只有以下主动入口，不存在复制后自动翻译：

1. Pico 面板选中条目后按 `T`。
2. 条目右键菜单选择“翻译”。
3. 按全局快捷键 `⌥ ⇧ T`，翻译当前系统剪贴板中的文本。

全局翻译快捷键可以在设置中修改或关闭。

### 4.2 支持范围与方向

- 仅翻译文本内容；图片、文件和无法提取文本的条目不显示翻译入口。
- 文本包含中文时，目标语言为英文。
- 文本不包含中文时，目标语言为简体中文。
- Pico 可以为决定目标语言而检测当前文本，但检测本身不触发翻译。
- 首版不提供其他目标语言、翻译历史、多轮对话或自动总结。

### 4.3 请求状态

1. 用户触发翻译后，当前条目显示低干扰的“翻译中”状态。
2. 请求在后台执行，Pico 不提前显示灵动岛，也不覆盖系统剪贴板。
3. 用户可以继续关闭面板或切换应用；翻译任务仍可完成。
4. 同一条目已有进行中的任务时，再次触发不会创建重复请求。
5. 新的全局翻译请求可以取消上一个尚未完成的全局请求。

## 5. 翻译灵动岛

### 5.1 出现时机

灵动岛仅在翻译成功或失败后出现，固定在当前活动屏幕顶部中央。它不获取键盘焦点，不切换当前应用，也不阻挡用户继续输入。

### 5.2 成功状态

收起状态包含：

- “翻译完成”及翻译方向。
- 单行译文摘要。
- “复制”按钮。

交互规则：

- 点击“复制”将完整译文写入系统剪贴板，按钮变为“已复制”，随后灵动岛自动收起。
- 点击灵动岛的其他区域展开原文与完整译文。
- 展开状态仍保留复制按钮。
- 不自动粘贴、不替换原条目，也不保存独立翻译历史。

### 5.3 失败状态

- 显示简短、可理解的失败原因，不展示响应体中的敏感信息。
- 主操作变为“重试”。
- 点击重试后灵动岛收起，请求重新进入后台执行；只有新结果返回后才再次出现。
- 配置无效时提供进入“AI 模型”设置页的次要入口。

### 5.4 自动收起

- 复制成功后约 1 秒自动收起。
- 用户未操作时，成功状态在约 8 秒后收起；展开后停止自动计时。
- 失败状态不自动消失，直到用户重试、关闭或进入设置。

## 6. 设置与权限

“AI 模型”设置页包含模型列表、默认模型、翻译方向说明和完成提醒开关。模型编辑弹窗包含名称、Base URL、API Key、模型 ID、“获取列表”和“测试 Chat”。

Pico 不为翻译申请新的 macOS 系统权限。网络请求只发送用户主动要求翻译的当前文本，并在首次配置模型时明确说明这一点。

## 7. 错误与边界情况

- 未配置模型：主动翻译时打开模型配置引导，不发送请求。
- 剪贴板为空或不是文本：显示轻量提示，不显示灵动岛。
- 文本过长：按模型上下文限制截断前先提示用户；首版不静默截断。
- 请求超时：按失败状态显示，并允许重试。
- 用户在请求期间删除条目：请求可以完成，结果仍通过灵动岛展示，但不关联已删除条目。
- 用户点击复制译文后，Pico 的监听器应识别为内部写入，避免生成重复历史；是否将译文另存为新条目由后续版本决定。

## 8. 原型覆盖

交互原型位于 `docs/prototypes/pico-interaction-prototype.html`，应可审查以下状态：

- 条目右键菜单中的“翻译”。
- 选中条目后按 `T` 的翻译流程。
- 翻译中的条目反馈。
- 翻译完成后的灵动岛收起与展开状态。
- 复制完成状态。
- 翻译失败与重试状态。
- 模型新增、编辑、模型列表失败和 Chat 接口测试。
